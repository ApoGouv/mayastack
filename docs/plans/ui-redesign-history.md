# MayaStack UI Redesign History

This document is the append-only history of the UI redesign plan. Its plan-change log was moved verbatim from [the roadmap](ui-redesign-roadmap.md) on 2026-11-15; the current plan, statuses and decisions are in the roadmap.

- **Append-only:** existing entries are never rewritten or deleted. A correction or a later fact is a new entry.
- **Order:** entries are chronological, oldest first, and dated with the day the plan changed or the change was recorded. An entry that records earlier work after the fact is labelled "Retrospective".
- **References:** "section A" to "section G" refer to [the roadmap](ui-redesign-roadmap.md). Older entries' references to a completed task's entry ("UI-13's entry", or "UI-07 in section C") now refer to its record in [the task records](ui-redesign-task-records.md); "section C" itself still means the roadmap's status table, sequence and open tasks.
- **Commits:** a commit or pull request is cited only once verified in the repository's history.
